# Qiddiya Academy (QCTA) workbooks

Drop the QCTA trainer-utilization workbooks here. Any `.xlsx` whose file name
contains `QCTA` or `Qiddiya` is picked up automatically by `/api/qiddiya`, so
next month's file only has to be added to this folder — the same convention
app.R used for its `QIDDIYA_SEARCH_DIRS` scan.

Workbooks can also be added from the Qiddiya Academy tab at runtime; those are
stored in the browser and merged with whatever is committed here.
